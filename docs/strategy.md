# 策略说明

## 策略类型

这是一个基于 XGBoost 的**时序二分类策略**，预测标的次日涨跌方向。

- **标的**: 美股个股（默认 AAPL）
- **频率**: 日频
- **预测目标**: 次日涨跌幅是否 ≥ 阈值（默认 +0.2%）
- **模型**: XGBoost 二分类器
- **交易方向**: 仅做多（预测 ≥ 阈值时买入）

## 标签构建

```
future_return[t] = close[t+1] / close[t] - 1
target[t] = 1  当 future_return[t] >= threshold
            0  其他
```

关键设计决策：

1. **最后一行被显式丢弃**。因为 `close[t+1]` 对最后一行不存在，旧代码将 NaN 比较结果误标为 0（bug 已于 v0.2.0 修复）。
2. **阈值可配置**。默认 0.2% 覆盖了最小价格变动和交易成本后的微利空间。
3. **阈值不是调出来的**。当前默认值硬编码，未在验证集上优化（见 roadmap）。

## 特征工程

全部自实现，不依赖 `pandas_ta`：

| 特征 | 计算方式 | 经济含义 |
|------|----------|----------|
| `SMA5_diff` | 5 日均线的日变化率 | 短期趋势强度 |
| `SMA10_diff` | 10 日均线的日变化率 | 中期趋势强度 |
| `SMA20_diff` | 20 日均线的日变化率 | 长期趋势强度 |
| `RSI_14` | 14 日 Wilder RSI | 超买超卖信号 |
| `MACD_hist` | MACD 线与信号线的差值 | 动量方向与强度 |
| `Volume_SMA5_ratio` | 当日量 / 5 日均量 | 异常放量/缩量 |
| `vol` | 原始成交量 | 绝对流动性和关注度 |

特征选择考虑：

- **无原始价格**。价格是非平稳的，直接用会导致分布漂移。所有价格特征都做了差分或比率处理。
- **无 SMA5 本身**。SMA5 与价格高度相关，仅保留其差分。
- **成交量同时保留比率和绝对值**。比率捕获相对变化，绝对值保留量级信息（大盘股 vs 小盘股不同）。

## 模型架构

```
XGBClassifier(
    n_estimators=200      # 树数量，控制模型容量
    learning_rate=0.01    # 低学习率 + 多棵树 = 更平滑
    max_depth=3           # 浅树，防止单树过拟合
    subsample=0.7         # 行采样，增加随机性
    colsample_bytree=0.7  # 列采样，防止对少数特征过依赖
    reg_alpha=1.0         # L1 正则化
    reg_lambda=1.0        # L2 正则化
)
```

正则化思路：低学习率 + 浅树 + 行列采样 + 双重正则化 = 强防过拟合。

## 交叉验证

使用 `TimeSeriesSplit(n_splits=5)`，保持时序顺序：

```
Fold 1: [train_1] [test_1]
Fold 2: [train_1 + train_2] [test_2]
Fold 3: [train_1 + train_2 + train_3] [test_3]
...
```

注意：当前实现未加入显式的 purge（清洗重叠样本）和 embargo（训练/测试间隔）。详见 `validation.md`。
